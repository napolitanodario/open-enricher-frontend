# Evaluation reports

The explorer is a read-only viewer of evaluation results generated by the OpenEnricher pipeline. Realtime evaluation is deferred and outside the current project scope.

## Supported workflow

1. Run metadata extraction and evaluation in the Python OpenEnricher project using its existing configuration.
2. Import the archive folder containing the per-video `score.json` files into the explorer.
3. Inspect scores, dimension weights, evaluator notes, usability thresholds and provider/model provenance in Overview; compare available reports across runs.
4. After the pipeline produces updated results, reimport the folder to refresh the displayed reports.

Missing reports are shown as not evaluated. Reports with provider errors or parse failures are shown as failed evaluations; fallback scores are excluded from quality comparisons.

The frontend does not call AI providers, request credentials, launch local agents or services, or modify imported score files. No API key, proxy or evaluation backend is required to use the explorer. Existing evaluation behavior in the Python project remains unchanged.
